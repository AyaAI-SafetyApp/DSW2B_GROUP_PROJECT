## Evaluation Criteria

Each project idea will be evaluated based on:

1. **Feasibility** (1-10 points)
   - Can be completed within the given timeframe
   - Matches team's skill level
   - Resources are available

2. **Learning Value** (1-10 points)
   - Provides learning opportunities for all team members
   - Covers course objectives
   - Introduces new technologies/concepts

3. **Innovation** (1-10 points)
   - Unique or creative approach
   - Solves a real problem
   - Has potential for future development

4. **Technical Complexity** (1-10 points)
   - Appropriate level of challenge
   - Demonstrates technical skills
   - Includes multiple technologies

5. **Team Collaboration** (1-10 points)
   - Allows for equal contribution from all members
   - Clear role distribution
   - Encourages teamwork
