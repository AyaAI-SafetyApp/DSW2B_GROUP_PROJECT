# Project Ideas

This directory contains all project idea submissions from group members.

## How to Submit Your Project Idea

1. Create a folder with your name (e.g., `john-doe/`)
2. Add your project idea documentation in your folder
3. Follow the template structure provided in `template/`

## Submission Requirements

Each project idea should include:
- **Project Title**: Clear, descriptive name
- **Description**: Detailed explanation of the project concept
- **Technical Requirements**: Technologies, tools, and skills needed
- **Timeline**: Estimated development phases and duration
- **Team Roles**: Suggested roles for team members
- **Feasibility**: Assessment of project complexity and requirements

## Presentation Formats

You can present your idea using:
- Word document (.docx)
- Slide deck (.pptx)
- Both formats for comprehensive presentation

## Voting Process

After all ideas are submitted, the group will:
1. Review all project ideas
2. Hold a meeting to discuss each proposal
3. Vote to select the two best ideas
4. Document the voting results in `voting-results.md`
