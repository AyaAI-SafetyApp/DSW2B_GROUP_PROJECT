# DSW2B_GROUP_PROJECT

## Project Ideas Phase

We are currently in the project ideas collection phase. Each group member should research and present a project idea for consideration.

### 📋 How to Submit Your Project Idea

1. **Read the Guidelines**: Check out [PROJECT_IDEAS_GUIDELINES.md](PROJECT_IDEAS_GUIDELINES.md) for detailed requirements
2. **Use the Template**: Find the template in `project-ideas/templates/` to structure your idea
3. **Choose Your Format**: Submit as a Word document, slide deck, or both
4. **Submit Your Idea**: Place your submission in the appropriate folder:
   - Documents: `project-ideas/documents/`
   - Slides: `project-ideas/slides/`

### 🗳️ Voting Process

After all ideas are submitted, we will:
- Review all submissions as a group
- Vote for the top 2 project ideas
- Select the winning projects for development

### 📁 Project Structure

```
project-ideas/
├── documents/          # Word docs and PDFs
├── slides/            # Presentation slides
└── templates/         # Templates and examples
```

### 🎯 What Makes a Good Project Idea?

- **Clear Problem**: Addresses a real need or problem
- **Feasible Scope**: Achievable within our timeline and skills
- **Technical Challenge**: Provides learning opportunities
- **Unique Value**: Offers something different or better
- **Team Suitability**: Matches our collective skills and interests

### 📞 Questions?

If you have questions about the submission process or need help, reach out to the group!
