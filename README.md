# DSW2B Group Project

Welcome to the DSW2B Group Project repository! This repository is organized to facilitate collaborative project development for our Data Structures and Web 2B course.

## 📋 Current Phase: Project Ideas

We are currently in the **Project Ideas** phase where each group member needs to research and propose project ideas for our group project.

### What You Need to Do:

1. **Research**: Take time to research and develop a project idea
2. **Document**: Create a detailed presentation of your idea
3. **Submit**: Add your project idea to the repository
4. **Participate**: Join the group meeting to vote on the best ideas

### Quick Start:

1. Navigate to the [`project-ideas/`](./project-ideas/) directory
2. Read the [submission guidelines](./project-ideas/README.md)
3. Use the [project template](./project-ideas/template/project-idea-template.md)
4. Follow the [presentation guidelines](./project-ideas/presentation-guidelines.md)
5. Submit your idea by the deadline

## 🎯 Project Selection Process

1. **Individual Research**: Each member researches and creates a project idea
2. **Submission**: Submit your idea with documentation and presentation
3. **Group Meeting**: Present ideas and discuss as a group
4. **Voting**: Vote to select the top 2 ideas
5. **Final Selection**: Choose 1 project from the top 2 for implementation
